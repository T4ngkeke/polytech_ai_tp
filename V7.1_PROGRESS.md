### Phase 1 — ingestion pipeline rework (`backend/worker/`) — main work, first
- `parsing.py`: pymupdf text extraction + **character-yield gate** → `needs_review` on bad PDFs
  (chars/page below threshold or high non-word ratio). Never silently ingest garbage.
- `chunking.py`: structure-aware chunking — split on heading/paragraph/exercise boundaries,
  **never cut an exercise or code block**, **detect & drop the TOC**.
- `ingest.py` rework: type/audience routing (from Document metadata) → Contextual Retrieval
  (worker LLM context, embed+BM25 the augmented text, store original `content`) → statement-only
  exercise extraction → build `tsv` (`to_tsvector`) → metadata enrichment → idempotent re-index.
- Upload endpoint `POST /api/teacher/labs/{id}/documents`: require `doc_type` + `audience`;
  enforce **PDF only**.
- Sample PDFs to test against: `docs/CM_book/`, `docs/CM_slides/`, `docs/TD/`, `docs/TP/`.
  Build CM_book (clean) end-to-end first as the vertical-slice smoke fixture.

### Phase 2 — multilingual kNN router (`backend/app/agent/router.py`) — parallel
- Keep exercise-number regex fast-path (already in `router.py`) → `agentic_search`.
- bge-m3 kNN over in-code multilingual anchor exemplars (embed once at startup); cosine nearest.
- Confidence threshold (`ROUTER_KNN_THRESHOLD`) → below → `rag` fallback + write `RouterQueryLog`.

### Phase 3 — hybrid retrieval + rerank (`backend/app/services/retrieval_service.py`) — needs PG
- Vector ANN + BM25 (`tsv`) recall → RRF/weighted fusion → reranker (`RERANK_URL`/`RERANK_MODEL`,
  faked in tests; degrade to fusion-only if URL empty) → top-k.
- Tenant + `audience='student'` filter enforced in the **SQL WHERE** after fusion/rerank.

### Phase 4 — self-eval bounded loop (`backend/app/agent/selfeval.py` + `graph.py`)
- Cheap gate (cosine threshold / empty recall) before any LLM.
- Guided 3-tier `good/partial/bad` verdict, one batched call; bad → rewrite query + re-retrieve,
  capped at `RAG_MAX_RETRIES` (default 1); final failure → disclaimer-tagged answer.
- Wire into the LangGraph agent; tool-call guided-decoding seam.

  `GET /api/teacher/documents/{id}/exercises` (number/statement, no solution).
