New worker modules + changes:

  `character_yield_gate` (low chars/page OR low word-char ratio → `GateResult(ok=False, reason)`).
  Verified against the real `docs/CM_book/INFO501.pdf`.
- `worker/routing.py` — `plan_for(doc_type) -> IngestionPlan(extract_exercises, contextual_retrieval)`.
  CM → contextual, no exercises; TD/TP → exercises, no contextual. Chunking always runs.
- `worker/chunking.py` — `chunk_pages(pages, doc_type) -> [Chunk(content, page_no, section)]`:
  drops TOC (dotted-leader / "table des matières" heuristic); TD/TP split on exercise boundaries
  (join-then-split so a cross-page exercise is never cut; code blocks stay intact); CM = paragraph
  chunks. Boundary regex covers exercice/exercise/exo/problème/problem.
- `worker/ingest.py` — rewritten pipeline: parse(+gate→`needs_review`) → chunk → Contextual
  Retrieval (`context_fn`, CM path; embed AND `tsv` over augmented `context+content`; original in
  `content`) → statement-only extraction (TD/TP, no solution) → denormalized `doc_type`/`audience`/
  `section`/`page_no` → `page_count` → `tsv` via `to_tsvector('simple', …)` **Postgres-only**
  (None on SQLite). Injectable `parse_fn`/`context_fn`; idempotent + failure-rollback kept.
- `worker/main.py` — threaded optional `context_fn` through `process_one`/`run_tick`/`run_forever`
  + `_make_real_context_fn` wired in `main()` (prod glue, no-cover).
- `services/document_service.py` + `routers/teacher.py` upload endpoint — now require `doc_type`
  (CM/TD/TP) + `audience` (student/teacher) Form fields and enforce **PDF-only** (400 otherwise);
  persisted on Document.

**Phase 1 follow-up to verify once Postgres is up:** the `tsv` `to_tsvector` population only runs
